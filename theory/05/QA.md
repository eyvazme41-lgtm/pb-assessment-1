# Вопрос 05. Независимые проверки и цепочка веток

## Вопросы

Объясните разницу между последовательными if...if...if...else и if...elif...elif...else. В каких ситуациях какой подход применять? Приведите примеры.

## Ответ
 в if...if...if...else проверятся будет каждый if a в if...elif...elif...else если if уже подходит то другие elif не будут смотрется и сразу перейдет к else и еще в первом else относится к последнему if -у а во втором else относится к первому if-у

 например: if 1 > 2:
               print(True)
           if  2 > 3:
               print(True)
           if 3 > 2:
               print(true)
            else:
               print(False)  здесь все if будут проверятся и else относится к последнему if 

            if 3 > 2:
               print(True)
           elif  2 > 3:
               print(True)
           elif 4 > 2:
               print(true)
            else:
            print(False) здесь если значеня if уже правда то elif -ы не будут проверятся  и else здесь относится к первому if -у
