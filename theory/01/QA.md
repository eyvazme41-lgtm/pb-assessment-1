# Вопрос 01. Переменные и ввод

## Вопросы

Что такое переменная? Как создать переменную? Как запросить данные с консоли?

## Ответ

Переменная это - коробка с именем котороя хранит в себе что-то
Просто дать ей имя и создать например: text = "main.py" здесь text это переменная
Написав input мы запрашиваем данные с консоли
