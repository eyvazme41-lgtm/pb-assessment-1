# Вопрос 02. Базовые типы и преобразование

## Вопросы

Какие базовые типы данных есть? В каких ситуациях какие типы данных используются? Какой тип данных получаем от input? Что такое type conversion?

## Ответ

Базовые данные это - int,str,bool,nonetype,float


int используется когда есть числа цифры например: count = ("1231")
str используется когда есть есть все что хочешь только нельзя только цифры писать например: text = ("main.py12@:")
bool это когда только True или False например: outside is rain = True or False другого значения нету
nonetype это пустота то есть нету значения 
float = все числа но с дробной частью например: 2.0
от input мы получаем  данный str
